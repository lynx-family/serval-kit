### 三、文本排版语法
1. **字体样式**
```latex
\textbf{加粗文字} \textit{斜体文字} \underline{下划线文字}
```
2. **列表**
```latex
% 无序列表
\begin{itemize}
  \item 第一项
  \item 第二项
\end{itemize}

% 有序列表
\begin{enumerate}
  \item 步骤一
  \item 步骤二
\end{enumerate}
```
3. **插入图片**
```latex
\includegraphics[width=0.8\textwidth]{你的图片路径.jpg}
```
